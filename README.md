# Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта

## Описание: Целью данной лабораторной работы является изучение основ языка Markdown и Latex. Markdown предназначен для быстрого написания важных текстовых документов с подробным форматированием. Latex предназначен для создания математических формул и выражений.
