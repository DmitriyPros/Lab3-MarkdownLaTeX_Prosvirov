## Лабораторная работа №3. Работа с Markdown-разметкой и базовое использование LaTeX в документации проекта
#### Markdown — это облегчённый язык разметки, который позволяет форматировать обычный текст с помощью простых символов.
#### Применяется в самых разных сферах: Разработка ПО, ведение заметок, блоги и контент, мессенджеры, создание учебных материалов.
#### Markdown нужен разработчикам, чтобы быстро и удобно работать с текстом — писать техническую документацию, инструкции, заметки, не отвлекаясь на сложное форматирование.
